## 1. 头像上传

### 1.1 多终端上传方式

- [ ] 冻结手机端头像上传交互：点击头像区域 → 弹出选择面板（拍照 / 从相册选择）
- [ ] 冻结电脑端头像上传交互：点击头像区域 → 文件选择器 / 拖拽 / 粘贴
- [ ] 确认头像只能有一张，上传新头像自动替换旧头像

### 1.2 头像裁剪

- [ ] 冻结头像裁剪交互：上传后弹出裁剪框 → 1:1 比例 → 支持缩放和拖动 → 确认/取消
- [ ] 确认第一阶段裁剪只支持 1:1 比例、缩放、拖动，不要求旋转和滤镜

### 1.3 头像规则

- [ ] 冻结支持的格式：JPG / PNG / WEBP
- [ ] 冻结单张大小上限：10MB
- [ ] 冻结上传后自动生成缩略图规则（200x200 + 80x80）
- [ ] 冻结未上传头像时的默认展示（性别默认头像）

## 2. 生活照上传

### 2.1 多终端上传方式

- [ ] 冻结手机端生活照上传交互：点击"添加照片" → 弹出选择面板（拍照 / 从相册选择，支持多选）
- [ ] 冻结电脑端生活照上传交互：点击"添加照片" → 文件选择器（多选）/ 拖拽多张 / 粘贴
- [ ] 确认一次可选多张上传

### 2.2 生活照规则

- [ ] 冻结数量上限：20 张
- [ ] 冻结支持的格式：JPG / PNG / WEBP / HEIC
- [ ] 冻结单张大小上限：15MB
- [ ] 冻结上传后自动生成展示图（800px 宽）和缩略图（200px 宽）

### 2.3 生活照管理

- [ ] 冻结照片网格展示交互（缩略图网格）
- [ ] 冻结拖拽排序交互（第一张为主展示图）
- [ ] 冻结单张删除交互（删除前确认）
- [ ] 冻结批量选择删除交互
- [ ] 冻结查看大图交互（点击缩略图 → 大图 → 左右滑动浏览）
- [ ] 冻结"设为头像"交互（选择生活照 → 弹出裁剪框 → 确认后替换头像，原生活照保留）

## 3. 认证材料图片上传

### 3.1 入口区分

- [ ] 确认认证材料图片不通过照片管理入口上传
- [ ] 确认认证材料通过认证流程上传（客户详情"认证"区域）
- [ ] 确认上传的图片进入 `profile_certifications.certification_items[*].material_refs`

### 3.2 认证材料上传交互

- [ ] 冻结手机端认证材料上传：点击"上传材料" → 拍照 / 从相册选择
- [ ] 冻结电脑端认证材料上传：点击"上传材料" → 文件选择器 / 拖拽
- [ ] 冻结支持的格式：JPG / PNG / PDF
- [ ] 冻结单个文件大小上限：20MB
- [ ] 冻结每种认证类型最多文件数：5 个
- [ ] 确认上传后可预览但不支持编辑
- [ ] 确认上传后不可公开访问，需权限验证
