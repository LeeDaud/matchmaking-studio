## 1. 通道一：PDF 拖入识别

### 1.1 PDF 解析能力

- [ ] 确认第一阶段支持的 PDF 类型：文本型（完整支持）、扫描型（降级支持）
- [ ] 确认不支持加密 PDF，需提示用户先解密
- [ ] 确认支持多页 PDF 逐页解析
- [ ] 确认文件大小上限（建议 20MB）

### 1.2 用户操作流程

- [ ] 冻结 PDF 导入入口位置（客户详情页 / 建档页的"导入资料"按钮）
- [ ] 冻结上传交互：拖入 + 点击选择
- [ ] 冻结解析中状态展示（"正在解析..."进度提示）
- [ ] 冻结解析结果预览界面布局（左侧 PDF 原文 / 右侧字段列表）
- [ ] 冻结每个提取字段的展示内容：字段名、提取值、置信度标识、原文出处高亮
- [ ] 冻结确认操作集合：逐项确认 / 批量确认 / 修改后确认 / 忽略
- [ ] 确认 PDF 原文件保存到 `supplemental_materials`（`kind = document`）

### 1.3 字段映射规则

- [ ] 冻结 PDF 解析层的标准化输出格式（field_key / extracted_value / normalized_value / confidence / evidence_text / page_number）
- [ ] 冻结"客户信息登记表"常见标签到冻结字段的映射表
- [ ] 确认映射目标必须以冻结字段字典为准，不允许发明中间字段
- [ ] 确认无法映射的内容先落入对应对象的 `notes` 备注字段
- [ ] 冻结枚举值转换规则（如"硕士" → `education_level = master`）
- [ ] 冻结数值提取和单位换算规则（如"2万" → `monthly_income = 20000`）
- [ ] 冻结区间拆分规则（如"28-35岁" → `preferred_age_min = 28` + `preferred_age_max = 35`）

### 1.4 异常处理

- [ ] 冻结 PDF 无法解析时的降级策略（文件仍保存，提示手动录入）
- [ ] 冻结解析结果为空时的处理（文件保存，提示未识别有效信息）
- [ ] 冻结部分字段低置信度时的处理（标记"待确认"，不进入批量确认）
- [ ] 冻结与已有值冲突时的处理（按冻结的冲突保护规则）
- [ ] 冻结文件过大时的处理（提示压缩后重试）

## 2. 通道二：录音转写+字段提取

### 2.1 录音转写能力

- [ ] 确认第一阶段支持的音频格式：MP3 / WAV / M4A / AMR
- [ ] 确认中文识别准确率目标（≥ 90%，普通话场景）
- [ ] 确认第一阶段不要求方言支持
- [ ] 确认建议支持多人对话区分（红娘 vs 客户）
- [ ] 确认建议支持时间戳
- [ ] 确认最大录音时长限制（建议 120 分钟）

### 2.2 用户操作流程

- [ ] 冻结录音导入入口位置（客户详情页"导入资料" → "录音导入"）
- [ ] 冻结上传交互：拖入 + 点击选择
- [ ] 冻结转写中状态展示（预估时长提示 + 支持后台处理）
- [ ] 冻结转写结果展示界面布局（上方转写文本 / 下方字段列表）
- [ ] 冻结字段原文出处的跳转交互（点击可定位到转写文本对应位置）
- [ ] 冻结确认操作集合（同 PDF 导入）
- [ ] 确认录音文件保存到 `supplemental_materials`（`kind = voice_note`）
- [ ] 确认转写文本保存到 `supplemental_materials`（`kind = document`）

### 2.3 字段提取策略

- [ ] 冻结对话语境理解规则（理解上下文，不逐句提取关键词）
- [ ] 冻结多轮确认优先规则（前后不一致时以最后一次明确表达为准）
- [ ] 冻结红娘复述优先规则（复述确认值优先级高于客户原始表达）
- [ ] 冻结模糊表达降级规则（不强行提取数值，标记低置信度）
- [ ] 冻结敏感字段保守提取规则（只在明确表达时才提取）

### 2.4 异常处理

- [ ] 冻结录音质量差时的降级策略（提示质量低，仍尝试转写）
- [ ] 冻结转写结果为空时的处理（录音文件仍保存）
- [ ] 冻结转写超时时的处理（转为后台任务，完成后通知）
- [ ] 冻结与已有值冲突时的处理（同 PDF 导入）
- [ ] 冻结格式不支持时的处理（提示支持的格式列表）
